# Portfólio Arthur — pacote completo para Vercel

Todos os arquivos deste pacote ficam juntos na raiz do repositório, como na
estrutura que você já enviou para o GitHub. Os caminhos do HTML e das fontes
foram ajustados para esse formato.

## Abrir localmente

Extraia o ZIP e abra index.html. Mantenha todos os arquivos juntos.

## Atualizar o GitHub e o Vercel

Extraia o ZIP e envie todos os arquivos para o mesmo repositório, substituindo
os arquivos existentes. Confirme em Commit changes. O projeto conectado no
Vercel pode iniciar o novo deploy automaticamente.

Configuração do Vercel:
- Application Preset: Other.
- Root Directory: ./ (index.html fica na raiz).
- Build Command: vazio.
- Output Directory: .
- Install Command: vazio.
- Nenhuma variável de ambiente é necessária.

## Contatos

Configure seus contatos reais no início de main.js. Campos vazios permanecem
inativos. Não é necessário editar os exemplos do terminal.
